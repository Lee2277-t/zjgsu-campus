## 一、应用简介

商砖小站是浙江工商大学同学的校园信息工具，个人开发，非官方应用。

## 二、核心功能

| 模块 | 能做什么 |
|---|---|
| 课程 | 查课程和老师、看评分评价，可写评价（默认匿名，可改可删）。 |
| 论坛 | 分板块发帖讨论，可匿名；另有树洞与漂流瓶。 |
| 闲置 | 发寻物招领与二手信息，另有学习资料共享，均为信息展示。 |
| 校园 | 校历倒计时、地点导航、活动，也可发起活动并接收报名。 |
| 我的 | 好友私信、收藏草稿、我的发布与申诉。 |
